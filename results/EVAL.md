# swimring evaluation

Generated by `go run ./cmd/swimring eval -seed 2002`. Every number below comes from a seeded, deterministic
simulation (package `sim`); re-running the command reproduces it exactly.
Defaults: T = 1 s probe period, 500 ms probe timeout, k = 3 relays, λ = 4, α = 4, β = 6,
one-way latency 1–4 ms. Latencies are in protocol periods T.

## 1. Failure detection vs cluster size and loss (Lifeguard on)
